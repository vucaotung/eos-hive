# Mẫu khung — Giai đoạn II (bước 10–15)

> **Mẫu khung, cần duyệt.** Chỉ là khung trình bày để soạn **bản nháp**; nội dung, căn cứ pháp lý, thẩm quyền ký và thành phần hồ sơ **phải đối chiếu quy định hiện hành** (tra theo `tra-cuu-phap-luat`) và biểu mẫu chính thức của cơ quan tiếp nhận. Mọi mục `[ ]` là chỗ chưa có thông tin: điền từ hồ sơ có nguồn hoặc để trống và đưa vào "Cần người cung cấp". Không ký, không nộp, không gửi.

| Mục | Trạng thái (đã có / chưa có / không áp dụng / cần xác nhận) | Bằng chứng ([tên-tệp], link) | Ghi chú |
| --- | --- | --- | --- |
| Điều kiện đầu vào (kết quả bước trước) | | | |
| Hồ sơ cần chuẩn bị (liệt kê theo quy định tra được) | | | |
| Căn cứ pháp lý đã tra (số hiệu, điều khoản, link, ngày tra) | | | |
| Cơ quan tiếp nhận/thẩm quyền và thời hạn xử lý (theo nguồn đã tra) | | | |
| Rủi ro, mốc hạn | | | |

## Đơn đề nghị (giao/thuê đất bước 10, cấp phép xây dựng bước 12, thẩm tra/ phê duyệt bước 11)

```
NHÁP – cần duyệt
ĐƠN ĐỀ NGHỊ [tên thủ tục]
Kính gửi: [cơ quan tiếp nhận]
Người đề nghị: [tên, địa chỉ, mã số — từ hồ sơ]
Nội dung đề nghị: [ ]
Căn cứ: [ ]
Hồ sơ kèm theo: [danh mục]
Cam kết: [theo mẫu chính thức của cơ quan]
```
